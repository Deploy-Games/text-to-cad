# 3D CAD Exports Directory

Exported 3D CAD model files ready for external CAD systems, 3D printing, and CAM.

- **STEP (`.step` / AP242):** Industry-standard parametric B-Rep solid format. Fully editable in **Onshape**, SolidWorks, Fusion 360, FreeCAD, and Rhino.
- **STL / 3MF:** For 3D printing (Bambu Studio, OrcaSlicer, PrusaSlicer).
- **GLB:** Interactive 3D visualization.
