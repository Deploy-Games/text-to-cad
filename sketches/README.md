# Sketches Directory

Drop your rough sketches, hand drawings, photos, or napkin drawings in this folder (or send them directly in chat or via Syncthing phone upload).

Supported input formats:
- `.png`, `.jpg`, `.jpeg`, `.webp`
- Annotated PDFs

The agent will read your sketches, extract dimensions and geometric features, and generate both 3D CAD models and dimensioned engineering drawings.
